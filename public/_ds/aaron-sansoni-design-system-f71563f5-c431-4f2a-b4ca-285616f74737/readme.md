# Aaron Sansoni Group — Design System

A brand & UI system for **Aaron Sansoni Group International (ASG)**, a global
business-education and personal-brand company. The house identity is built on
one voice — the founder, **Aaron Sansoni** — and a family of flagship programs
that each carry a signature color while sharing the same typographic and
structural DNA.

> **Source note:** This system is built on the **official ASGI Brand
> Guidelines** (`assets/ASGI-Brand-Guidelines.pdf`, "Income, Impact &
> Influence", 24pp), the ASG 2021 logo bank, program key-art ("holdslides"),
> and the licensed **Futura PT** font family. Colours, typography hierarchy,
> vision/values and logo rules below follow that document; program (Empire /
> Deal) event colours are documented extensions sampled from the key-art.

## The brands / products

- **Aaron Sansoni** — the master personal brand. Crown mark + `AARON SANSONI`
  wordmark. Monochrome (black / white), premium, understated.
- **Empire Mastery®** — flagship live event, *"World's #1 Empire Building
  Experience."* Signature **royal purple** on a cosmic/starfield backdrop.
- **Deal Mastery®** — sales & negotiation program. Signature **deep emerald
  green + gold**, delivered over 3 days (Day 1 / 2 / 3 holdslides).
- **Aaron Sansoni Performance Team (ASPT)** — coaching/consulting arm. Crown +
  `PERFORMANCE TEAM` lockup, monochrome.

All programs are fronted by Aaron himself; photography of him on stage or in a
pinstripe suit is a recurring hero device.

## CONTENT FUNDAMENTALS

**Voice:** Aspirational, authoritative, high-energy. Speaks in the language of
achievement — *empire, mastery, performance, deal, elite, #1, world-class*. It
is a challenger/mentor voice: it tells you what's possible and dares you to
claim it.

**Person & address:** Second person, direct — talks to *you* about *your*
empire, *your* deals, *your* next level. First person appears as Aaron's
personal endorsement ("I'll show you…"). Rarely neutral third-person.

**Casing — two registers:**
- **Core brand voice (official):** headings in **Title Case**, sub-headings in
  **Sentence case**, body in sentence case — all at **0 tracking**. This is the
  document/typography standard from the guidelines.
- **Event / key-art register (secondary):** program lockups use **ALL-CAPS with
  wide tracking** (`EMPIRE MASTERY`, `DEAL MASTERY`, `DAY 1`) and a tracked
  all-caps eyebrow `AARON SANSONI` (~0.22em). Use this deliberately for event
  hero art and capsules — not as the default for prose.

**Punctuation & marks:** Registered marks (`®`) are shown on program names.
Superlatives use the numeral form (`#1`, `World's #1`). Exclamation is used
sparingly but the tone is emphatic without it.

**Examples (verbatim from key-art):**
- Eyebrow: `AARON SANSONI`
- Program: `EMPIRE MASTERY®` · `DEAL MASTERY®`
- Tagline capsule: `WORLD'S #1 EMPIRE BUILDING EXPERIENCE`
- Session marker: `DAY 1`

**Emoji:** None. The brand is premium and restrained — no emoji, no casual
internet tone. Icons are geometric/linear, used sparingly.

**Vibe:** Luxury seminar / high-ticket mastermind. Think black-tie business,
stage lights, wealth, ambition — never playful or pastel.

## VISUAL FOUNDATIONS

**Typeface — Futura PT, exclusively** (official brand typeface). A geometric
sans across the entire identity. Weights run Light→Heavy: **Heavy/Bold** for
primary headings, **Demi** for sub-headings & in-text headings, **Book** for
intro & body copy, **Light** for large body. Official hierarchy (guidelines
p.13): Primary Heading = Futura PT Heavy, Title Case, 45pt/54pt leading, **0
tracking**; Sub-heading = Demi, Sentence case, 32pt; Intro = Book 15pt; Body =
Book 12pt. The **core voice is Title/Sentence case at 0 tracking.** The
UPPERCASE + wide-tracked treatment seen in the `EMPIRE MASTERY` lockups is the
secondary **event/key-art** register, not the base prose style.

**Color (official palette).** **Primary: Black `#000000` + White `#FFFFFF`.**
**Secondary: Light Grey `#C2C6C0` + a Gold Gradient** (`#BB9244 → #DDB54F →
#E5D387 → #F4DC75 → #B08F4B`). Gold is fundamentally a **gradient**; a solid
`#DDB54F` stands in for flat fills. Silver/gold gradients add contrast &
hierarchy against the mono base. **Program event colours are extensions, not
core brand:** Empire Mastery royal purple `#693090` on cosmic `#160823`; Deal
Mastery event-gold `#E4A025` on deep emerald `#01150C`. Discipline: large
neutral fields, gold used sparingly for hierarchy.

**Backgrounds.** Dark, full-bleed, atmospheric. Empire uses a **starfield /
nebula**; Deal uses a **near-black textured green**. Portraits of Aaron are
color-graded to the program hue (purple wash / green wash) and blended into the
backdrop. Backgrounds are photographic + gradient, never flat brand-color
blocks and never busy patterns behind text.

**Solid capsules.** A recurring device: a **solid rectangular color block**
holding a short all-caps line (purple band = `WORLD'S #1…`; gold block =
`DAY 1`). Sharp corners, high contrast, tight padding. Used for
taglines/markers, not for buttons.

**Photography (official).** *"Vibrant, energetic, dynamic, engaging"* — sets
the tone for the brand as a **model of success and creating change.** Imagery
should express that Aaron Sansoni offers **life-changing experiences**:
on-stage energy, engaged audiences, confident portraiture. High contrast,
cinematic. Program key-art color-grades Aaron's portrait to the program hue.

**Gradients.** Radial/vignette darkening at the edges of hero art to protect
text; subtle diagonal light streaks (see the AS master holdslide). No candy or
blue-purple UI gradients.

**Corner radii.** Crisp. Cards and inputs use small radii (4–10px); pills
(999px) are reserved for buttons/tags. Capsule labels are square (0).

**Cards.** White (or `--ink-900` on dark), hairline `--ink-200` border, soft
low-spread shadow (`--shadow-sm`/`md`). Not heavily rounded, no colored
left-border accents.

**Shadows.** Neutral, soft, low-spread (`rgba(10,10,10,0.06→0.16)`). A special
`--shadow-gold` glow is reserved for primary gold CTAs.

**Borders.** Hairline neutral (`1px --ink-200`) for structure; `2px` gold or
ink for emphasis/inputs on focus.

**Motion.** Quick and eased — `120–360ms`, `ease-standard`/`ease-out`. Fades
and short rises; **no bounce, no springy overshoot.** Decorative loops avoided.

**Hover / press.** Hover = darken filled surfaces one step (or lift with
shadow); ghost/outline fill with a faint tint. Press = slightly darker + a
1px downward nudge (no scale-down bounce).

**Transparency & blur.** Used for overlays on photography (dark scrims at
40–70% over hero images) and occasional frosted panels on dark art. Sparing.

**Imagery grade.** Warm on the master brand (neutral B&W + gold), cool-royal
for Empire, deep-green for Deal. High contrast, cinematic, slight vignette.

## ICONOGRAPHY

- **The crown is the brand's core mark.** A five-point crown (see
  `assets/logos/crown-black.png` / `crown-white.png`) sits between `AARON` and
  `SANSONI` in the primary lockup and stands alone as an app/avatar mark. It is
  the single most important brand symbol — use the supplied PNG, never redraw
  it.
- **No proprietary icon font** was supplied. For UI glyphs the system uses
  **Lucide** (https://lucide.dev) via CDN — a thin, geometric, open-source line
  set whose 2px stroke and rounded-square proportions match Futura PT's
  geometry. This is a **substitution** (flagged — see CAVEATS); swap for the
  brand's own set if one exists.
- Icons are **line/stroke**, monochrome, inheriting `currentColor`. Fills are
  avoided except the crown.
- **No emoji.** No decorative unicode dingbats.
- Program/logo lockups are shipped as PNG in `assets/logos/`; use those rather
  than typesetting the names by hand where a real lockup is available.

## CAVEATS
- **Official guidelines now incorporated** (`assets/ASGI-Brand-Guidelines.pdf`).
  Colours, typography hierarchy, vision/values and logo rules follow it. The
  guidelines cover the master brand only — Empire/Deal **program event colours**
  (purple, emerald) are extensions taken from the key-art, kept scoped under
  `[data-brand]` and clearly labelled as non-core.
- **Icon set is a substitution** (Lucide via CDN) — no official ASG icon set
  was provided.
- Some white-on-transparent logos (Performance Team white, ASPT) appear blank
  on light backgrounds — that is expected; use the black variants on light.
